# End-to-End Retail Analytics Project

This project is meant to be built by you, step by step. The goal is not to generate a polished dashboard automatically. The goal is to learn and practice the real Data Analyst workflow.

## Project goal
Use the Sample Superstore dataset to build practical skills in:
- Excel data cleaning and reporting
- SQL business analysis
- Python / Pandas exploratory analysis
- Power BI storytelling and dashboard communication

## Core principle
Do not fabricate findings. Every insight must be based on actual analysis performed from the raw data.

## Evidence-backed findings
The dataset contains 9,994 rows and 21 columns, with zero missing values and zero duplicate rows. The business generated $2,297,200.86 in sales and $286,397.02 in profit, with a 12.47% profit margin. Technology was the strongest category, while Furniture underperformed due to loss-making Tables and Bookcases. Consumer sales were the largest segment and the West region generated the strongest revenue.

## Important rules
- Do not claim final business decisions without evidence.
- Keep the dashboard narrative tied to actual measurements.
- Use the Power BI layer to communicate the findings already validated in Excel, SQL, and Python.
