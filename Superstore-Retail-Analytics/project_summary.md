# End-to-End Retail Analytics Project Summary

## Problem
The business needed a complete retail analytics project that could show how sales, profit, customer behavior, and product performance were performing across the Superstore dataset. The real challenge was not just creating visuals, but doing the actual analytical work correctly: cleaning the data, validating quality, answering business questions, and only then building the dashboard story.

## Solution
The project was built in a structured end-to-end workflow using Excel, SQL, Python, and Power BI.

### 1. Excel
- Checked row count and column count
- Reviewed missing values, duplicates, and invalid records
- Validated date fields and suspicious numeric conditions
- Created important fields such as Shipping Days and Profit Margin %
- Prepared the dataset for business analysis

### 2. SQL
- Calculated total sales, profit, orders, customers, and quantity
- Analyzed performance by category, region, and segment
- Identified top products and loss-making sub-categories
- Reviewed monthly sales trends and customer value

### 3. Python / Pandas
- Performed exploratory data analysis
- Verified the dataset was clean and analysis-ready
- Calculated KPI summaries and trend patterns
- Helped confirm business findings with actual data

### 4. Power BI
- Used as the final communication layer for storytelling and executive reporting
- Designed to present KPI cards, trends, and product/category performance visually
- Built after the analysis was verified, so the dashboard reflects actual findings rather than assumptions

## How the project works
This workflow mirrors a real data analyst process:

1. Raw data enters the project
2. Excel performs the first data quality check
3. SQL answers structured business questions
4. Python explores deeper patterns and validates trends
5. Power BI turns the verified insights into a dashboard for decision-making

This ensures the work is evidence-based and suitable for interviews, portfolio presentation, and business communication.

## Verified project findings
The dataset was clean and complete:
- 9,994 rows
- 21 core columns
- 0 missing values
- 0 duplicate rows
- 0 invalid sales or discount issues

### Business performance
- Total Sales: $2,297,200.86
- Total Profit: $286,397.02
- Profit Margin: 12.47%
- Total Orders: 5,009
- Total Customers: 793
- Average Order Value: $458.61

### Category performance
- Technology: highest sales and profit
- Furniture: lower profitability
- Office Supplies: strong and stable performance

### Key business risks
- Furniture sub-categories were loss-making, especially:
  - Tables
  - Bookcases
  - Supplies

### Regional and segment performance
- West region had the strongest sales and profit
- Consumer segment generated the highest sales volume

## Final takeaway
This project shows the full end-to-end data analytics workflow, from raw data quality checks to business insight generation and dashboard storytelling. It demonstrates practical data analysis skills, SQL logic, Python EDA, and business communication through Power BI.
